# DORA Evidence Matrix — Teaching Model

| Capability | Architecture Evidence | Operational Evidence | Governance Evidence |
|---|---|---|---|
| Critical services | service map | service catalogue state | owner approval |
| Dependencies | dependency graph | runtime discovery / tests | review record |
| BIA | BIA document | recovery metrics | business/risk sign-off |
| Resilience | HLD/DCA | failover/chaos results | architecture decision |
| Incidents | observability design | incident timeline/RCA | incident governance |
| Third parties | provider map | SLA/incident evidence | due diligence/contract |
| Exit | exit architecture | rehearsal results | approved strategy |
| RoI | data model/mapping | validation/reconciliation | reporting ownership |
| TLPT | scope architecture | test deliverables | authority/governance |

## Principle
Evidence should be attributable, timestamped, reviewable and scoped.
