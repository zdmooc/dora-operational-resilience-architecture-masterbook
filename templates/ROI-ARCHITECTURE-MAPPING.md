# Register of Information ↔ Architecture Mapping

## Purpose
Teaching mapping between RoI records and enterprise architecture. This is NOT the official filing template.

| RoI concept | Architecture object | Example |
|---|---|---|
| Financial entity | Legal Entity | MayaBank SA |
| Contractual arrangement | Contract | Cloud Agreement 001 |
| ICT third-party provider | Provider | Cloud Provider A |
| ICT service | Technology/Service | Managed Kubernetes |
| CIF supported | Business Function | Instant Payments |
| Data/location | Information/Location | Payment data / EU |
| Subcontractor | Provider relationship | Provider B |
| Exit | Initiative/Control | Migration Plan |

## Reconciliation controls
- stable IDs;
- owner;
- source system;
- last update;
- legal entity scope;
- service taxonomy;
- provider hierarchy;
- duplicate detection;
- unknown fields;
- approval workflow.
