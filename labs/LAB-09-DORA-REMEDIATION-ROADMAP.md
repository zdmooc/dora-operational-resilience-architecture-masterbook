# Lab 09 — DORA Remediation Roadmap

## Findings
Assume:
- incomplete dependency map;
- untested provider exit;
- no common RTO catalogue;
- single IAM dependency;
- RoI not reconciled with architecture;
- DR tests component-centric only.

## Build roadmap
### 0–30 days
Discovery, owners, critical services, evidence inventory.

### 30–90 days
Dependency baseline, BIA harmonisation, priority test scenarios.

### 3–6 months
Provider/subcontractor analysis, exit designs, observability/evidence gaps.

### 6–12 months
End-to-end exercises, exit rehearsal, platform remediation.

### Strategic
Architecture simplification, concentration reduction, portability and governance automation.
