# Lab 05 — Exit Strategy

## Scenario
Exit from Managed Event Streaming Provider A.

## Tasks
Design:
1. alternative target;
2. schema/topic/config export;
3. identity migration;
4. keys/certificates;
5. data/replay migration;
6. dual publishing;
7. consumer migration;
8. cutover;
9. rollback;
10. provider data deletion/evidence.

## Measure
Estimate exit duration and identify which assumptions require contractual confirmation.
