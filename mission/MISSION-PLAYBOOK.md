## Discovery questions
1. What service must continue?
2. Which function is critical/important?
3. What are the authoritative data stores?
4. Which dependency stops the service immediately?
5. Which dependency can be delayed?
6. Which shared service creates concentration?
7. Which provider has no alternative?
8. When was exit last tested?
9. Which recovery objective is business-approved?
10. Which claim is measured vs assumed?
