# Glossaire bilingue / Bilingual Glossary

| FR | EN | Sens architecture |
|---|---|---|
| Résilience opérationnelle numérique | Digital operational resilience | Continuité fiable des services financiers malgré perturbation ICT |
| Fonction critique ou importante | Critical or Important Function (CIF) | Fonction dont la disruption peut materially impair l'entité |
| Risque ICT | ICT risk | Risque lié aux systèmes, données, réseaux, sécurité et fournisseurs ICT |
| Tiers ICT | ICT third-party provider | Fournisseur externe de services ICT |
| Sous-traitant | Subcontractor | Fournisseur d'un fournisseur dans la chaîne de service |
| Risque de concentration | Concentration risk | Dépendance excessive à un provider/service/region/control plane |
| Réversibilité | Reversibility | Capacité à reprendre/migrer service et données |
| Stratégie de sortie | Exit strategy | Plan organisé de sortie fournisseur/service |
| Analyse d'impact métier | Business Impact Analysis (BIA) | Évalue conséquences d'interruption |
| RTO | Recovery Time Objective | Délai cible de restauration |
| RPO | Recovery Point Objective | Perte temporelle de données acceptable |
| Mode dégradé | Degraded mode | Service minimum pendant indisponibilité |
| TLPT | Threat-Led Penetration Testing | Test réaliste piloté par threat intelligence |
| RoI | Register of Information | Registre des arrangements ICT tiers |
| Preuve | Evidence | Artefact démontrant contrôle/test/décision |
| Blast radius | Blast radius | Étendue d'impact d'une défaillance |
| Dépendance transitive | Transitive dependency | Dépendance indirecte via d'autres composants |
| Service minimum viable | Minimum viable service | Fonctionnalités minimales à maintenir/reprendre |
